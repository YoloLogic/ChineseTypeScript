# ChineseTypeScript 教学教程 —— 从零学会写汉语 TypeScript

> 这本教程教你三件事：**汉语关键字怎么用**（每个都给出对应的英文）、
> **原本那套符号怎么用**（`{}` `()` `;` `=>` `?.` `??` … 一个没换）、
> **基础标准库怎么用**（这一条有个重要前提，见下）。
>
> ⚠ **与 Chinese++ 的一个重大差别**：Chinese++ 连标准库都做了汉化层
> （`#包含 <向量>`、`标准::向量<整数>`）。**ChineseTypeScript 只汉化了语言关键字**，
> `console` / `Array` / `Map` / `JSON` 这些**运行库的名字没有中文别名**，
> 一律照写英文（英文永远可用）。
>
> **本文件是生成物，不要手改。** 由 `tools\make_tutorial_chts.ps1` 把
> `教程\例子\*.chts` 的真源码与「期望输出」切进 `教程\教程模板.md` 生成。
> `tests-chts\judge_tutorial.ps1` 会**真编译真运行**每个例子并核对输出，
> 同时核对本文件与例子是否逐字一致 —— 所以教程里的代码**必然能跑**。

---

## 怎么用这本教程

1. 先读「第 0 课」把编译命令跑通。
2. 每课都有一份**能直接编译运行**的例子，放在 `教程\例子\`。
3. 例子开头的注释里写了它自己的**期望输出** —— 你跑出来的应当一模一样。
4. 汉语写法和英文写法**可以混着写**，同一行里混都行。

## 第 1 课 程序骨架

### 本课关键字

| 汉语 | 英文 | 干什么 |
|---|---|---|
| `函数` | `function` | 定义函数 |
| `返回` | `return` | 从函数返回 |
| `空型` | `void` | 「什么也不返回」 |

| `//` | 行注释 | 到这里行尾都不算代码 |
| `" "` | 双引号 | 字符串 |
| `+` | 加号 | 数字相加；**字符串拼接**也用它 |

## 第 2 课 变量与类型

### 本课关键字

| 汉语 | 英文 | 干什么 |
|---|---|---|
| `常量` | `const` | 之后不许重新赋值（**首选**） |
| `局部变量` | `let` | 可以重新赋值，作用域限制在块里 |
| `变量` | `var` | 老写法，作用域是整个函数（**新代码别用**） |
| `接口` | `interface` | 描述一个对象长什么样 |
| `类型别名` | `type` | 给类型起名字 |
| `数字` `字符串` `布尔` | `number` `string` `boolean` | 基本类型 |
| `真值` / `假值` | `true` / `false` | 布尔字面量 |
| `空值` | `null` | 「空」 —— 值和类型两种位置都能用 |
| `未定义` | `undefined` | 「未定义」 —— **当类型可以，当值要写英文**（附录 C） |

| `\|` | 联合类型：`字符串 \| 未定义` 读作「字符串或未定义」 |
| `?` | 可选属性：`名字?: 字符串` |
| `[ ]` | 元组类型：`[字符串, 数字]` —— 按位置标类型 |

## 第 3 课 运算符与符号

**本课最重要的一句话：符号一个都没换。**
注意与 C++ 的差别 —— C++ 有「运算符替代拼写」（`并且`/`或者`/`并非`），
**TypeScript 这边没有**，`&&` `||` `!` 照写。

### 本课符号

| 类别 | 符号 | 说明 |
|---|---|---|
| 算术 | `+` `-` `*` `/` `%` | `+` 也用于字符串拼接 |
| 比较 | `===` `!==` `==` `!=` `<` `>` `<=` `>=` | **推荐 `===` / `!==`**（严格相等，不做类型转换） |
| 逻辑 | `&&` `\|\|` `!` | 与或非 |
| 空值合并 | `??` | 左边是 `空值`/`undefined` 时才取右边 |
| 可选链 | `?.` | 左边是空就整个表达式给 `undefined`，不报错 |
| 三元 | `? :` | `条件 ? 真时 : 假时` |
| 赋值 | `=` `+=` `-=` `*=` `/=` | `甲 += 1` 等价 `甲 = 甲 + 1` |
| 自增自减 | `++` `--` | |
| 展开/剩余 | `...` | `[...表甲, 3]` 把数组摊开；函数参数里把剩下的收起来 |
| 模板串 | `` ` `` 与 `${}` | `` `你好，${名字}` `` |
| 类型相关 | `:` `\|` `&` `<>` `?` `!` | 标注、联合、交叉、泛型、可选、非空断言 |

### 讲解

* **`===` 和 `==` 的区别**：`===` 要求类型也相同，`==` 会做类型转换。

## 第 4 课 分支与循环

### 本课关键字

| 汉语 | 英文 | 干什么 |
|---|---|---|
| `如果` / `否则` | `if` / `else` | 分支 |
| `选择` | `switch` | 多分支 |
| `情形` | `case` | 选择里的一个分支 |
| `默认` | `default` | 选择的兜底分支 |
| `对于` | `for` | 计次循环 |
| `遍历` | `of` | `对于 (常量 项 遍历 表)` —— 遍历元素 |
| `属于` | `in` | 「某个键在不在对象里」 |
| `每当` | `while` | 先判断再执行 |
| `执行` | `do` | 先执行一次再判断（搭配 `每当` 收尾） |
| `跳出` / `跳过` | `break` / `continue` | 结束整个循环 / 跳过本轮 |

### 本课符号

| 写法 | 说明 |
|---|---|
| `如果 (条件) { … }` | 条件用 `( )` 包起来 |
| `如果 … 否则 { … }` | `否则` 前不写分号 |
| `选择 (值) { 情形 1: … 跳出; 默认: … }` | `情形` 后是**冒号**，每个 `情形` 末尾要 `跳出` |
| `对于 (初值; 条件; 步进) { … }` | 三段用**分号**隔开 |
| `执行 { … } 每当 (条件);` | `do-while`：末尾那个 `每当` 后面必须有 `;` |
| `对于 (常量 项 遍历 容器) { … }` | 范围遍历 |

## 第 6 课 类与接口

### 本课关键字

| 汉语 | 英文 | 干什么 |
|---|---|---|
| `类型` | `class` | 定义类（**注意：不是「类」**，汉语关键字不少于两个字） |
| `接口` | `interface` | 描述形状 |
| `继承` | `extends` | 继承父类 |
| `实现` | `implements` | 声明实现某个接口 |
| `构造器` | `constructor` | 构造方法 |
| `自身` | `this` | 当前对象 |

| `重写` | `override` | 声明「我改写了父类的成员」 |
| `公开` `私有` `受保护` | `public` `private` `protected` | 访问控制 |

| `继承 父类 实现 接口` | **都用空格**，不像 C++ 那样用冒号 |

## 附录 C 常见坑

| 坑 | 现象 | 怎么办 |
|---|---|---|
| 单字关键字不存在 | 写 `类` 编不过 | 汉语关键字**不少于两个字**：`class` 是 `类型`，不是 `类` |
| 想当然的译名 | 写 `超级`、`可空` 报「找不到名字」 | 按附录 B 的表写：`super` 是 **`父类`**，`null` 是 **`空值`** |
| ~~`未定义` 当值不行~~ | **已修**（见下） | 值与类型两种位置都能写 `未定义`；`空值`(null) 同理 |
| 库的成员是英文 | 写 `表.尺寸` 报「没有该属性」 | 运行库的名字没汉化：用 `表.length`、`console.log` |
| 模块路径写中文 | 编译过但运行时找不到模块 | 路径是字符串，必须原样：`来自 "./数学"` |
| `选择` 忘 `跳出` | 会串到下一个 `情形` | 每个 `情形` 末尾写 `跳出` |
| `==` 与 `===` 混用 | 出现古怪的类型转换 bug | 一律用 `===` / `!==` |
| `||` 当默认值 | `0`、`""` 被当成「假」而取默认值 | 只在「可能为空」时用 `??` |
| 忘了 `--rewriteRelativeImportExtensions` | 显式写 `"./数学.chts"` 时产物路径不对 | 推荐**无扩展名导入**（`"./数学"`），见 `tests-chts\proj\` |

### 案例：`未定义` 当值曾经不行 —— 现在修好了

这条值得留着，因为它演示了「让汉语关键字**真正等价**于英文」会卡在哪些地方。

**症状**：`常量 甲 = 未定义;` 报 `TS2304 找不到名字`；而 `: 未定义`（当类型）完全正常。

**根因**：`null` / `true` / `false` 是 JS 的**字面量**，词法关键字直接变成字面量节点，
打印器再从**种类**取规范拼写 —— 所以 `空值` 与 `null` 完全等价。
但 `undefined` 在 JS 里**不是字面量**，而是全局对象上的一个**名字**：
上游把它按**文字**注册成全局符号（`checker.go` 里的 `c.globals["undefined"]`），
值位置也按普通标识符解析。于是汉语拼写两头落空：

* 解析时查 `c.globals["未定义"]` → 查不到；
* 产物又会把 `未定义` 原样打印成标识符，而 JS 里没有这个全局名 → 运行时 `ReferenceError`。

**修法（两处，都落在边界上）**：

1. **解析器**：值位置把标识符文本归一化成规范拼写 `undefined`
   （`parser.parseUndefinedKeywordExpression`）—— 解析与类型一次解决；
2. **打印器**：当节点文本是 `undefined` 而**源码拼写不是**时，用节点文本而不是切源码
   （`printer.getTextOfNode`）—— 否则汉语拼写照样进产物。

**关键约束：只归一化【值位置】。** 属性名与成员名是运行时的真实属性名，必须原样保留：

```ts
常量 戊 = { 未定义: 1 };      // 属性名就叫「未定义」，产物里也是 未定义
console.log(戊.未定义);        // 成员名同理
```

这件事由 `tests-chts\undefined.chts` 靶子 + 判定第 11 节**永久钉住**：
它同时断言「值位置是 `undefined`」与「属性名仍然是 `未定义`」。

### 顺带说：为什么要真编译

这条边界**不是读文档读出来的，是真编译撞出来的**。
如果教程只是照着关键字表抄一遍、不实际编译运行，读者会抄到一段跑不起来的中文代码。
这也是为什么本教程的每个例子都由 `tests-chts\judge_tutorial.ps1`
**真编译、真运行、逐行核对输出**，而且那个判据自带自测（改坏必须被抓）。

## 那，英文怎么办？

**照样用，而且可以混着写。** 例如：

```ts
常量 表: Array<number> = [1, 2, 3];     // 汉语关键字 + 英文类型名
函数 加倍(值: number): number { 返回 值 * 2; }
console.log(表.map(加倍));
```

汉语不是替换英文，是**并行多出来的一种拼写**。
这也是为什么「随便拿一个开源 TypeScript 项目，用我们的编译器编，照样编得过」。
