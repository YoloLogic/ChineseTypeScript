# 标准库汉化 —— 翻译底稿

## 这是什么

`名字清单.tsv` 是【TS 标准库汉化】的**翻译底稿**：从上游 107 个 `lib.*.d.ts`
（`tsc/internal/bundled/libs/`）里抽出**全部名字**，去重后 **7687 条**。

格式（TAB 分隔，三列）：

```
kind     english          译名
global   Array
member   push
```

* `kind = global`：全局类型/值（`Array`、`Math`、`console`、`Promise` …）—— **2445 条**
* `kind = member`：接口成员（`push`、`length`、`toString` …）—— **5242 条**
* 第三列 `译名` 留空，由翻译逐步填（翻译是本项目的长期工作）

## 单一真源与守卫

* **真源是上游 lib 文件**，不是这份清单（清单是生成物）。
* 生成/核对：`pwsh -File tools\gen_stdlib_names.ps1`（`-Check` 只核对）。
  上游 lib 一变，`-Check` 就会红，逼我们重新生成并复核翻译。
